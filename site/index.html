Build and install

These machines run on custom OP-XY firmware built with the Open-XY SDK. That is unofficial and experimental: you install it at your own risk. You can always go back by installing the official OS update from teenage engineering.

  1. Set up the SDK as described in first machine.
  2. Test a machine: python sdk.py test --machine path/to/op-silicon/machines/<id>
  3. Build and install the firmware as described in build.
